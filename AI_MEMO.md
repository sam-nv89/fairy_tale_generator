## Критически важные архитектурные решения

### Роутинг
Весь роутинг — через `st.session_state.current_page`. Доступные значения: `landing`, `generator`, `profile`, `privacy`, `terms`. Смена страницы всегда + `st.rerun()`.

### После выхода
```python
sign_out()
st.session_state.current_page = 'landing'
st.rerun()
```
Если не установить `current_page`, пользователь остаётся на генераторе (неаутентифицированный) вместо лендинга.

### Hero-сниппеты лендинга (landing.py)
- Заголовки и badges — Python f-string (мгновенный рендер, никакого JS ожидания).
- Текст — JS typing-эффект (начинается сразу при появлении DOM-элементов).
- Высота карточек фиксирована в CSS: `height: 7.5em; overflow: hidden;`.
- JS prefill-шаг **удалён** — он вызывал flash полного текста перед анимацией.

### Авторизация (auth.py)
- SessionBounded PKCE Flow — каждый браузер получает уникальный `client_id` через Cookie.
- IsolatedDiskStorage — сессии хранятся в `.auth_sessions/` (не в git, в .gitignore).
- Graceful fallback — если Supabase недоступен, приложение работает в гостевом режиме.

### Локализация профиля (profile_page.py)
- Словарь `L` содержит все 8 языков: ru, en, es, fr, de, pt, zh-CN, hi.
- `loc()` — фолбэк: `lang → en → ru` через `or` (не вложенные `.get()`).
- Ключ `del_confirm_word` — слово подтверждения удаления переводится для каждого языка.

### 🔄 Миграция на google-genai SDK (10.03.2026)
Проведена миграция с устаревшего `google-generativeai` на современный `google-genai` SDK.  
**Ключевые изменения для будущих агентов**:
1. Импорт: `from google import genai`.
2. Клиент: `client = genai.Client(api_key=api_key)`.
3. Генерация: `client.models.generate_content(model=model_name, contents=prompt)`.  
**Внимание**: новый SDK автоматически загружает API-ключ из переменной окружения `GOOGLE_GENAI_API_KEY`, если он не передан в конструктор. В проекте ключ передается явно из `st.secrets`.
