# 🧚 Инструкции для Gemini по проекту «Генератор Аудио-Сказок»

Этот файл содержит контекст, правила и стандарты разработки для ИИ-агента, работающего с данным репозиторием.

## 📝 Обзор проекта
**Генератор Аудио-Сказок** — это персонализированный веб-сервис для родителей, который создает сказки с помощью ИИ и озвучивает их нейронными голосами.
- **Версия:** v4.0 (Активная разработка)
- **Технологии:** Python 3.10+, Streamlit, Google Gemini (Flash 2.0/Lite), Edge-TTS, Supabase (Auth/DB).
- **Локализация:** Полная поддержка 8 языков (RU, EN, ES, FR, PT, ZH-CN, HI, DE).

## 🚀 Запуск и Тестирование
- **Запуск приложения:** `python -m streamlit run app.py`
- **Тестирование:** `pytest tests/ -v`
- **Конфигурация:** Все секреты хранятся в `.streamlit/secrets.toml` (Gemini API, Supabase URL/Key).

## 🛠 Архитектурные стандарты
Проект следует принципам Senior Software Engineering:
1. **Модульность:** 
   - `app.py`: Маршрутизация (routing) и основной UI генератора.
   - `landing.py`: Лендинг с Premium UX/UI (Glassmorphism).
   - `auth.py`: SUPABASE Auth (PKCE Flow).
   - `storage.py`: Гибридное хранилище (Supabase Cloud + Local JSON fallback).
   - `i18n.py`: Централизованная система переводов и ИИ-промптов.
2. **UI/UX ("Wow" Effect):** 
   - Использование кастомного CSS в `styles.py`.
   - Поддержка Dark/Light тем.
   - Плавающий HTML5 плеер с караоке-подсветкой текста.
3. **Управление состоянием:** Роутинг через `st.session_state.current_page`.

## 📜 Протоколы взаимодействия (Mandatory)
При работе с проектом Gemini **ОБЯЗАНА** соблюдать следующие правила из `gemini.md`:

### 1. START Protocol
Перед началом любой задачи прочитайте:
- `DEV_LOG.md`: Последние технические изменения.
- `AI_MEMO.md`: Заметки об архитектурных решениях и "подводных камнях".
- `ARCHITECTURE.md`: Текущая структура системы.

### 2. END Protocol (Reverse Chronological Logging)
После выполнения задачи добавьте запись в начало (под заголовок) следующих файлов:
- `DEV_LOG.md`: Что было сделано технически.
- `AI_MEMO.md`: Если приняты новые архитектурные решения или найдены нюансы.
- Обновите `APP_VERSION` в `config.py`, если изменения значительны.

### 3. Инженерная гигиена
- **TypeScript Excellence в Python:** Строгая типизация, отсутствие `any`-подобной логики, использование интерфейсов (Pydantic или TypedDict при необходимости).
- **Zero-Waste:** Не создавать временные `.txt` или `.md` файлы. Вся документация в коде или существующих `.md` файлах.
- **Язык общения:** Все планы и диалоги на **Русском языке**. Комментарии в коде и Git-коммиты на **Английском**.

## 📂 Ключевые файлы
- `app.py`: Главный оркестратор (God Object, требует осторожного рефакторинга).
- `config.py`: Единый источник истины для констант, моделей и версии.
- `i18n.py`: Маппинг 8 языков, включая системные промпты для Gemini.
- `auth.py`: Критическая логика авторизации, изолированная по `client_id`.
- `styles.py`: Огромный модуль CSS (~1600+ строк), требует аккуратности при вставках.
