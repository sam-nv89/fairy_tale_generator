## 📁 Структура

- `audit_summary.md` — краткая сводка по аудиту проекта
- `tech_debt.md` — список технического долга по приоритетам
- `quick_wins.md` — быстрые улучшения (1-2 часа)
- `refactor_plans.md` — планы по рефакторингу
- `security_notes.md` — заметки по безопасности
- `meeting_notes.md` — заметки по обсуждениям и решениям

## 🔴 Критические проблемы

1. **app.py — "God Object"** — 1470 строк, нарушает SRP
2. **Дублирование i18n** — 3 независимых модуля переводов
3. **Нет rate limiting** — уязвимость для злоупотреблений
4. **Отсутствие CI/CD** — ручное тестирование и деплой

## 🟡 Проблемы среднего приоритета

1. **Дублирование кода** — расчет возраста в 2 местах
2. **Magic strings** — рассеяны по коду без констант
3. **CSS/HTML в Python** — смешение логики и представления
4. **Неполная валидация** — не все инпуты санируются
