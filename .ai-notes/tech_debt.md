## 🔴 КРИТИЧЕСКИЙ ПРИОРИТЕТ

### TD-001: app.py — "God Object" (1470 строк)
**Файл:** `app.py`
**Проблема:** Нарушает Single Responsibility Principle
**Влияние:** Сложность тестирования, поддержки, понимания
**Решение:** Выделить модули:
- `routing.py` — маршрутизация
- `story_generator.py` — бизнес-логика
- `tts_processor.py` — аудио обработка
- `ui_components.py` — UI компоненты

**Статус:** 📋 Запланировано
**Оценка:** 2-3 дня

### TD-002: Дублирование i18n модулей
**Файлы:** `i18n.py`, `landing_i18n.py`, `legal_i18n.py`
**Проблема:** 3 независимые системы переводов
**Влияние:** Несогласованные ключи, сложное добавление языков

```
translations/

├── landing.py

└── profile.py
```

**Статус:** 📋 Запланировано
**Оценка:** 1 день

### TD-003: Отсутствие rate limiting
**Файл:** Требуется новый `rate_limiter.py`
**Проблема:** Нет ограничений на генерации/авторизацию
**Влияние:** Уязвимость для DoS и злоупотреблений
**Решение:** Добавить декоратор rate_limit:
```python
@rate_limit(max_calls=3, period=3600)
def generate_story(...):
    ...
```

**Статус:** 📋 Запланировано
**Оценка:** 2 часа

### TD-004: Отсутствие CI/CD pipeline
**Файл:** Требуется `.github/workflows/ci.yml`
**Проблема:** Нет автоматических тестов
**Влияние:** Human error risk, регрессии
**Решение:** GitHub Actions workflow:
```yaml
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - run: pip install -r requirements.txt
      - run: pytest tests/ -v
```

**Статус:** 📋 Запланировано
**Оценка:** 1 час

### TD-008: Неполная валидация инпутов
**Файлы:** `profile_page.py`, `app.py`
**Проблема:** Не все пользовательские входы валидируются
**Влияние:** Риск XSS, injection
**Решение:** Добавить `sanitize_input()` в `utils.py`:
```python
def sanitize_input(text: str, max_length: int = 500) -> str:
    return html.escape(text.strip())[:max_length]
```

**Статус:** ⏳ Готово к реализации
**Оценка:** 30 минут
