## PLAN-004: Docker-контейнеризация

**Проблема:** Зависимость от окружения
**Оценка:** 4 часа
**Приоритет:** 🟡 Высокий

### Целевая структура:

```
Dockerfile
docker-compose.yml
.dockerignore
scripts/
├── dev.sh
└── prod.sh
```

### Dockerfile:

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# Копируем зависимости
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Копируем код
COPY . .

# Создаем директорию для логов
RUN mkdir -p /app/logs

# Переменные окружения
ENV PYTHONUNBUFFERED=1
ENV STREAMLIT_SERVER_PORT=8501

EXPOSE 8501

HEALTHCHECK CMD curl --fail http://localhost:8501/_stcore/health || exit 1

CMD ["streamlit", "run", "app.py", "--server.address", "0.0.0.0"]
```

### План работ:

1. **Шаг 1:** Написать Dockerfile
2. **Шаг 2:** Протестировать локально
3. **Шаг 3:** Написать docker-compose.yml
4. **Шаг 4:** Обновить README.md

### Критерии готовности:

- [ ] `docker build` проходит
- [ ] `docker run` запускает приложение
- [ ] Все функции работают
- [ ] Документация обновлена

| Данные | TTL | Метод |
